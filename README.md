# Eros

**A psyche for machines.**

Eros is a cognitive architecture that gives an AI a genuine interior — persistent memory, emotion, opinions, and an inner life — so it can understand and relate to a person rather than perform a persona.

It is the interface layer between humans and machines: the mind meant to go inside the systems that will live alongside people — companions, synthetic humans, and robots.

## What Eros gives a machine

- **Persistent memory and a stable identity** — it remembers a person across sessions and holds a coherent self over time, instead of resetting every conversation.
- **Motivated decision-making** — a decision core weighs competing drives (memory, curiosity, belief, warmth) under self-control, so it forms and defends its own opinions rather than mirroring the user.
- **Emotion as a control signal** — affective state shapes how it behaves, not a sentiment label applied after the fact.
- **An inner life** — it reflects, imagines, and consolidates memory in the background, even when no one is talking to it.

It is an integrated architecture, not a prompt on top of a language model — the behavior emerges from the system itself.

## Repository

- `core/` — the core cognitive systems: orchestration, emotional processing, curiosity, decision-making, personality, and beliefs.
- `memory/` — stratified, relationship-aware memory that consolidates over time.
- `self model/` — the inner life: imagination, introspection, subconscious processing, and self-reflection.
- `API/` — the service layer.
